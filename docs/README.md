# 题解文档

- 命名格式：`{LeetCode编号}-{英文题名}.md`（与 codes 对应）
- 开头先放一分钟复习，再保留题干、输入输出、示例，兼顾快速回忆与完整复习
- 内容围绕：决策链、核心不变量、关键状态变化、正确性、复杂度、易错点、自测和迁移
- 内含跳转到对应 Go 文件的链接

## 叙述风格（与 AGENTS.md 一致）

- **首次出现的知识点**（双端队列、前缀和、滑动窗口等）：2～4 句话说明是什么、本题里干什么
- **思路**：先写「怎么想到」（朴素方法 → 瓶颈 → 可复用信息 → 当前解法），再写「怎么做」
- **篇幅**：简洁为主，思路部分约一到两屏；简单题可合并章节，状态变化直观时可省略执行过程
